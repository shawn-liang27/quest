# PLAN
The goal is to make a streaming VideoLLM fire precisely — to decide when to emit a proactive response so that it speaks at the moments a standing query is actually satisfied and stays silent otherwise. The firing decision is made per frame from the model's hidden state, which already attends over the full history of past frames via the KV cache and has the query available in context; the problem is that this representation combines that available information too weakly to separate query-relevant event frames from non-event frames, so no firing threshold yields usable precision and the model over-fires across all task types. The approach is therefore to strengthen how the query conditions the per-frame representation that feeds the firing decision — not by adding temporal context or memory, which the KV cache already provides, but by making the representation read its existing context through the query so that query-relevant event presence becomes linearly separable — thereby raising the event/non-event separability of the firing signal and, with it, firing precision across alerting, counting, state-monitoring, and the other proactive tasks.
